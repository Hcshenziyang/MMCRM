# 简单介绍
喵喵CRM是一个客户关系管理系统，具备用户、权限管理、客户管理、项目管理等功能。
主要采用python的Django框架，前后端分离，数据库MySQL,缓存Redis，前端使用uni-app（vue）。

## 部分细节注意
- setting文件最好将开发、测试、上线不同环境下配置区分开来，要不然就会在测试、上线时面临无穷无尽的调整和错误。
  配置文件区分两种思路，当然也可以两者结合（本项目采用两者结合，结构清晰+环境变量管理便捷）：
  拆分文件：
      原来的文件路径：mycrm/settings.py
      现有的文件路径：mycrm/settings/base.py │dev.py | prod.py | (test.py)
          base.py存放：项目路径、应用列表、模板配置、认证设置等。
          dev.py存放开发配置。
          prod.py存放生产上线配置。
  采用.env文件管理：
      .env环境配置文件（放在根目录下mycrm即可）（需求pip install python-decouple）
