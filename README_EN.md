# Overview
MeowMeow CRM is a customer relationship management system with user & role/permission management, customer management, and project management modules.
It’s built with Python’s Django framework (API-first, frontend–backend separated), MySQL for the database, Redis for caching, and a uni-app (Vue) frontend.
